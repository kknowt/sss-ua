# Благодійний фонд «Стабілізейшен суппорт сервісез»

Modern remake of [sss-ua.org](https://sss-ua.org/) — a Ukrainian charity working to overcome the social consequences of war.

## Stack

- Vite
- React + TypeScript
- React Router
- Framer Motion

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

Ukrainian is the default language. Use **EN / UA** in the header to switch.
